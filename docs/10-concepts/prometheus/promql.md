## Data Types
* Scalar: A single numeric floating-point value
* Instant vector: A set of time series, each with a single value at a specific timestamp
* Range vector: A set of time series, each with a range of data points over a specified time duration
* String

## Literals
String, scalar-float, and duration literals can be used in PromQL.

## Operators
Arithmetic, comparison, logical, and aggregation operators are supported by PromQL
